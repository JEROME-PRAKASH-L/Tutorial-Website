# Tutorial Website Learning Roadmap

This roadmap keeps the tutorial project easy to extend as new lessons are added.

## Suggested lesson structure

Each tutorial should include:

1. A short statement of the problem.
2. A minimal working example.
3. An explanation of the important decisions.
4. A small exercise for practice.
5. Links to the next related lesson.

## Quality checklist

Before publishing a lesson:

- Verify every code example from a clean starting point.
- Use descriptive headings and accessible link text.
- Keep examples focused on one concept.
- Mention prerequisites and expected output.
- Update navigation when a new lesson is added.

The goal is to help learners move from copying an example to understanding and adapting it.
